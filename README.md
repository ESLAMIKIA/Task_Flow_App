## 📱 About TaskFlow

TaskFlow is a simple yet powerful productivity application designed to help you build better habits and achieve your goals.

Whether you want to maintain daily routines or accomplish bigger life goals, TaskFlow gives you a clean and motivating space to track your progress.

## ✨ Features

- ☀️ **Daily Tasks** — Create and track recurring daily activities.
- 🎯 **Long-term Goals** — Manage your bigger goals and achievements.
- 📅 **Interactive Calendar** — Switch between weekly and monthly views.
- 🔥 **Daily Streaks** — Keep track of your consistency.
- 🏆 **XP & Level System** — Earn experience points and level up.
- 📊 **Progress Tracking** — Visualize your daily productivity.
- 🎉 **Celebration Effects** — Enjoy confetti animations when completing tasks.
- 🎨 **Custom Task Icons** — Choose icons and colors for your activities.
- ⏳ **Deadlines** — Set deadlines for your tasks.
- 💾 **Local Storage** — Save your tasks directly on your device.

## 🛠️ Built With

| Technology | Description |
|---|---|
| Kotlin | Main programming language |
| Jetpack Compose | Modern declarative UI |
| Material 3 | UI components and theming |
| Compose Animation | Smooth animations and transitions |
| SharedPreferences | Local data persistence |
| JSON | Task data serialization |

## 🎮 XP & Level System

TaskFlow includes a simple gamification system to keep you motivated.

| Action | XP |
|---|---:|
| Complete a daily task | +10 XP |
| Complete a long-term goal | +25 XP |
| Reach the next level | Every 100 XP |

Your progress is automatically calculated based on your completed activities.

## 🎨 Design

TaskFlow features a modern dark interface with:

- Purple gradient accents
- Rounded cards and smooth shadows
- Animated progress indicators
- Custom bottom navigation
